# Checklist del modulo 2

Antes de cerrar el modulo, verifica que puedes explicar y ejecutar:

* que es un pipeline modular;
* que problema resuelve Airflow;
* como se define un DAG;
* como se serializa un modelo;
* como FastAPI valida entradas;
* como se prueba una API de prediccion;
* que contiene un Dockerfile;
* como se publica una imagen en ECR;
* que relacion tienen ECS cluster, task definition y service;
* como evitar costos eliminando recursos cloud al terminar.
