# Resultados de aprendizaje

Al finalizar este modulo, el estudiante estara en capacidad de:

* disenar pipelines de entrenamiento modulares y automatizables;
* diferenciar el rol de datos, codigo, configuracion y artefactos;
* construir DAGs de Airflow para entrenar y evaluar modelos;
* serializar modelos con formatos apropiados para produccion;
* crear APIs de inferencia con FastAPI y contratos Pydantic;
* contenerizar servicios de ML con Docker;
* reconocer alternativas de despliegue en AWS, Azure y GCP;
* desplegar una API Dockerizada en AWS ECS Fargate.
