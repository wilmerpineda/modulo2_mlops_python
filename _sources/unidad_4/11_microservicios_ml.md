# Unidad 4: Introduccion a microservicios para ML

Un microservicio de ML expone una capacidad puntual, por ejemplo prediccion de `session_minutes`.

Ventajas:

* despliegue independiente;
* escalamiento separado;
* contrato HTTP claro;
* integracion con otros sistemas.

Riesgos:

* latencia;
* versionado de contratos;
* monitoreo de calidad;
* compatibilidad entre modelo y codigo.
